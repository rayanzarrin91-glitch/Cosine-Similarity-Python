# Cosine-Similarity-Python
This Program Has Powered By Python.
You Can Describe Your Story About your Favorite Cartoon To Model And Model Can Give You Your Best Match Cartoon In a Dashboard.
This Model Has Powered By Algorithms Like Cosine Similarity, TfIdfVectorizer And Modules Like NumPy, Pandas, Matplotlib.
This Program Also Has a Normal Chart (Bell Chart) From Datas In DataFrame.

Requirements:

Scikit-Learn
NumPy
Pandas
Matplotlib
